# 🌍 Global News

Modern, responsive ve çok dilli bir global haber portalı arayüzü.

Global News; haberleri, son dakika gelişmelerini, finansal piyasaları, video haberleri ve popüler içerikleri modern bir kullanıcı deneyimiyle sunmak için hazırlanmış tek dosyalık bir HTML5 frontend projesidir.

## 📌 Proje Hakkında

Global News, modern haber platformlarının temel kullanıcı deneyimlerini tek bir frontend dosyasında bir araya getiren bir web arayüzü projesidir.

Proje özellikle:

- Haber portalı geliştirmek isteyen geliştiriciler
- Frontend öğrenenler
- HTML5 / CSS3 / JavaScript projeleri geliştirenler
- Açık kaynak projeleri inceleyenler
- Kendi haber platformunu oluşturmak isteyenler

için başlangıç noktası olarak kullanılabilir.

## ✨ Özellikler

### 📰 Haber Sistemi

- Son dakika haberleri
- Öne çıkan haberler

- En çok okunan haberler
- Haber detay ekranı
- Haber kategorileri

### 🌍 Çoklu Dil

## 🔎 Arama

Global News içerisinde frontend tabanlı arama arayüzü bulunmaktadır.

Kullanıcılar haber içerikleri içerisinde arama yapmak üzere arama ekranını kullanabilir.

Gerçek bir backend entegrasyonu ile:

- Haber arama
- Kategori filtreleme
- Tarih filtreleme
- Yazar filtreleme
- Etiket filtreleme

gibi özellikler eklenebilir.

---

## 👤 Üyelik Arayüzü

Projede:

- Giriş yap
- Kayıt ol
- Üyelik arayüzü

bulunmaktadır.

> ⚠️ Mevcut sürümde üyelik sistemi yalnızca frontend UI seviyesindedir.

Gerçek kullanıcı sistemi için backend, veritabanı, şifre hashleme, session/JWT ve güvenlik katmanları gereklidir.
